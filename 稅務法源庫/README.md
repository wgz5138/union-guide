# 稅務法源庫（AI 會計師知識庫）

這個資料夾是「AI 會計師」的**法律依據來源**。目的：讓 AI 在回答稅務問題時，
都能對應到**法條條號與官方原文連結**，避免憑印象、避免拿過期數字回答。

> ⚠️ **免責聲明**
> 1. 本資料夾為**整理／摘要**，方便快速定位，**非正式法律或稅務意見**。
> 2. 凡標示「原文節錄」者為節錄，仍**以全國法規資料庫最新公告版本為準**（每個檔案都附官方連結）。
> 3. **法條文字相對穩定，但金額（級距、免稅額、扣除額）逐年公告**，請搭配
>    [`07-年度數字-114年度.md`](07-年度數字-114年度.md) 使用，每年更新。
> 4. 重大決策（出售不動產、農地移轉、繼承）前，務必再向會計師／地政士／國稅局確認。

## 🧭 情境 → 法條對照表

| 你遇到的情境 | 主要法源 |
|---|---|
| 綜所稅級距、我會被課多少 | 所得稅法 §5、§17 |
| 薪資、利息、租賃、各類所得 | 所得稅法 §14 |
| 股利要合併還是分開計稅 | 所得稅法 §15 |
| 自提勞退 6% 可不可以扣 | 勞工退休金條例 §14（摘要見 01 檔） |
| 自住房屋稅 1.2% / 囤房稅 | 房屋稅條例 §5 |
| 自用住宅地價稅 2‰ | 土地稅法 §17、§34、§41 |
| 繼承房屋將來賣（舊制 vs 房地合一） | 所得稅法 §4-4、§4-5 |
| 農地是什麼、有沒有在農用 | 農業發展條例 §3、§38 |
| 農地買賣免不免土增稅 | 土地稅法 §39-2 |
| 農地繼承免不免遺產稅 | 遺產及贈與稅法 §17 |
| 水稻保護區／特定農業區是什麼 | 區域計畫法施行細則 §11、§13 |
| 農地能不能租、租金怎麼課 | 所得稅法 §14（第五類）、農業發展條例 |

## 🔄 每年怎麼更新

1. 每年 11 月底，財政部公告**次年度**免稅額、扣除額、級距 → 新增一份
   `07-年度數字-1XX年度.md`。
2. 法條若修正，回各法的全國法規資料庫連結抓最新版，更新「原文節錄」。
3. 個人狀況變動（加薪、結婚、買賣不動產、農地動向）→ 更新
   `00-個案結案報告.md`。
