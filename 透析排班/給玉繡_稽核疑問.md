# 給玉繡的稽核疑問（可直接貼 LINE 轉傳）

玉繡姐～稽核名單想做成「自動排」，有幾個地方要跟妳確認一下，麻煩妳了 🙏（用講的、語音都可以）

**【最重要的一題】**
1️⃣ 妳排「**整個月**」的稽核名單時，是看「**哪一週**的班表」排的？
　→ 是看該月「**第一週**」的班表就能排完整個月嗎？還是要**等好幾週**的班表才排得出來？

**【其他小問題】**
2️⃣ 同一個人怎麼決定排「**週一三五**」還是「**週二四六**」那一組？是看他自己那週**有上班的日子**嗎？

3️⃣ 如果某一區、某一班真的**排不出本區的人**，要從**另一區借人**嗎？還是稽核**不跨區**？

4️⃣ 如果有人當月**白班、小夜都有上**，算白班還是小夜？

5️⃣ 「一週稽核兩次」是**稽核者自己挑兩天**對吧？所以程式只要排到「**誰＋第幾班**」就好，不用排到「哪兩天」，對嗎？

—
（這些確認好，自動排稽核名單就能完成囉，感謝配合 🙏）
