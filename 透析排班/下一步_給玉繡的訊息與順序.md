### 📌 第二件：LINE 自動發，麻煩妳先辦「金鑰」

辦好之後，每週六名單就能**自動貼到品管群**，不用手動複製。
步驟有點多但都很簡單，**任何一步卡住就拍照/截圖傳我**，我陪妳弄 👍

**① 開申請網頁**
　手機或電腦打開：`developers.line.biz/console`
　按「**Log in**」，用妳平常的 **LINE 帳號**登入（會跳手機確認，按同意）。

**② 建一個「提供者 Provider」**
　登入後按「**Create a new provider**」→ 名字隨便打，例如「**透析品管**」→ Create。

**③ 建一個「機器人頻道」**
　在剛剛那個 provider 裡按「**Create a Messaging API channel**」，填：
　・Channel name（名稱）：例如「**印藥水小幫手**」
　・Region / 地區：選 **Taiwan（台灣）**
　・類別：隨便選「醫療 / 其他」都可以
　・下面打勾同意條款 → **Create**。

**④ 拿「金鑰」（最重要的一串）**
　進到剛建好的頻道 → 上面分頁點「**Messaging API**」
　→ 拉到最下面找「**Channel access token (long-lived)**」
　→ 按「**Issue / 發行**」→ 會出現一長串英數字
　→ **整串複製，私訊傳給我**（這串就是金鑰🔑，別貼到群組裡）。

**⑤ 把機器人加成好友**
　同一頁上面有一個 **QR code（方形條碼）**
　→ 用手機 LINE 的「掃描」掃它 → 把這個機器人**加為好友**。

**⑥ 把機器人邀進品管群**
　到妳要發名單的那個 **LINE 品管群組** → 邀請成員 → 把這個機器人**拉進群**。

**⑦ 通知我**
　做到這裡傳一句「**好了**」給我，剩下最後一個技術小設定我自己用程式處理，不用妳弄 🙆

> 💡 小提醒：這個方式是 LINE 官方的「Messaging API」，免費額度一個月可發很多則，我們一週才發一次，完全夠用、不用付錢。

### 技術備忘（給工程端，玉繡不用看）
- **LINE Notify 已停用**（2025 年收掉），所以走「Messaging API」是現在唯一簡單路線。
- **group id 取得**需要一個臨時 webhook 或小程式接收一次群組訊息來抓，這步由工程端做（玉繡只要把機器人加進群並傳一句話）。
- 免費方案 push message 有月額度上限，一週一次綽綽有餘。
- 維持「逐格擇優法」；稽核名單規則明朗後若變很複雜，再評估 OR-Tools。
