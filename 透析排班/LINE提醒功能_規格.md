# LINE 提醒功能 — 規格（個別私訊為主）
> 建立：2026-06-13　|　動機：組員常忘記印藥水，害夜班班長 / leader 被波及、招來抱怨。群組提醒發太多會麻木 → 改用「個別私訊」精準提醒本人。

## 目標
讓「輪到的人」在該印的前一天/當天，收到**只給他一個人**的 LINE 提醒，降低漏印。

## 設計
### 1. 個別私訊提醒（主要，解決漏印最有效）
- 機器人私訊本人，例：`🔔 雅雯，明天(6/17)輪到妳印「一區」藥水，記得印喔！🙏`
- 只有本人收得到，群組看不到 → 每則都跟自己有關，不會麻木。
- 時機：**前一天提醒 + 當天再補一次**（額度吃緊時可降為只發當天一次）。
- 備案：沒加好友 / 拿不到 ID 的人 → 自動退回「群組提醒」，不整個失效。

### 2. 群組公告（輔助）
- 只在**週六發一次**「下週整份名單總覽」當公告，不每天洗群。

### 3.（選配）漏印回報
- 班長發現沒印 → 群裡回關鍵字 → 程式記一筆，月底看誰常漏（為了精準提醒，非究責）。

## 前置條件 / 技術需求
- LINE 規定：機器人**只能私訊有加它好友的人**。
  → 需 **15 位組員每人加機器人好友一次**（掃 QR，永久有效）。
- 加好友/傳訊時 webhook 會給該人的 **userId** → 程式自動建立「userId ↔ 姓名」對照表存檔。
- 需要 LINE 官方帳號 **Channel access token（金鑰）** + webhook 接收 userId / group id。
  ⚠️ 金鑰**不要進 git**，放本機環境變數或單獨設定檔。
- 免費額度約每月 200 則；個別提醒估每月 50~100 則，夠用。
