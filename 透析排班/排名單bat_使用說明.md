# 排名單.bat — 一鍵產生名單 使用說明
> 給玉繡（小白）用的「免打指令」版本。

## 安裝（只做一次）
把 `排名單.bat` 放到 **`F:\透析排班\`**（跟 `排班.py` **同一個資料夾**）。
> 建議：在桌面建一個「排名單」捷徑指到它，更好按。

## 怎麼用（兩種，挑一種）
1. **拖放（最簡單）**：把醫院給的班表 Excel，用滑鼠**拖**到 `排名單.bat` 上**放開** → 名單自動跑出來。
2. **雙擊**：直接點兩下 `排名單.bat` → 視窗會請你**貼上班表路徑**，貼好按 Enter。

跑完視窗會停住，看完按任意鍵關閉。產生的名單在 `F:\透析排班\輸出\`（Excel + 可貼 LINE 的文字）。

## 常見狀況
- **顯示 [錯誤] 找不到 Python**：表示 conda 環境路徑變了。用記事本打開 `排名單.bat`，把這行改成正確的 python.exe 路徑：
  `set "PYEXE=C:\Users\wgz51\.conda\envs\medbid\python.exe"`
- **中文變亂碼**：本檔已用 `chcp 65001`（UTF-8），Windows 10/11 正常。若仍亂碼，不影響名單產生，輸出檔照樣正確。
- **找不到班表檔**：確認拖的是 `.xls` 班表本身，路徑沒有打錯。
- **指定某一週分頁**：拖放只會用「最新一週分頁」。要指定舊的某週，得用原本的 PowerShell 指令在最後加分頁名（進階，平常用不到）。

## 注意
- `排名單.bat`、`排班.py`、各個 `.csv` 設定檔要在**同一資料夾**。
- 這支只用 Python 跑，**不需要網路 / Claude / Max**。
