# 手機網頁版 — 一次性部署（給小巫）

> 用 Streamlit Community Cloud 免費架，架好得到一個網址，玉繡手機開那網址就能用。

## 部署步驟（約 5 分鐘，做一次）
1. 開 https://share.streamlit.io → 用 **GitHub 帳號登入**。
2. 按 **Create app / New app**。
3. 設定：
   - Repository：`wgz5138/union-guide`
   - Branch：選目前這個分支（或合併到 main 後選 main）
   - **Main file path：`透析排班/webapp/app.py`**
4. 按 **Deploy**，等它跑完（第一次裝套件較久）。
5. 完成後會給一個網址（像 `https://xxxx.streamlit.app`）→ **把網址傳給玉繡**。

## 玉繡用法（手機）
1. 開那個網址。
2. 選「🟦 每週印藥水」或「🟩 每月稽核」。
3. 上傳班表 Excel（先把班表檔存到手機：在文書電腦下載後用 LINE 傳給自己即可）。
4. 印藥水→選那一週分頁；稽核→選年月。
5. 按排班 → 名單直接出現在畫面（跨區標 🔺）→ 可下載 Excel / 文字 / 雲端貼上版。

## 注意（目前版本）
- 這版是「**看名單 + 下載**」。每次都用 repo 內的記憶檔當基準。
- **記憶自動累積（排完自動往前推）+ 線上微調 + 自動接 LINE 提醒**＝下一階段再加。
- 班表要「Excel 檔本人」，截圖不行。
