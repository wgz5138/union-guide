# 給玉繡：建立 LINE 機器人 + 拿金鑰（超白話版，照著點就好）

玉繡姐～這份照著一步一步點就好，**任何一步畫面跟我寫的不一樣、或卡住，就直接拍照傳我**，不用緊張 🙂
（建議用手機，但畫面小；有電腦更好操作）

━━━━━━━━━━━━━━━
**PART 1：建機器人、拿「金鑰」**（這part做完傳金鑰給我就好）
━━━━━━━━━━━━━━━

**第 1 步**　點進「透析品管」
　在 Providers 那頁，點一下「**透析品管**」這個字。

**第 2 步**　建立機器人頻道
　進去後找一個按鈕寫「**Create a Messaging API channel**」
　（或先按「Create a channel / 建立頻道」，再選「**Messaging API**」）→ 點它。

**第 3 步**　填資料（看到欄位就填，沒寫到的留空或預設）
　・**Channel name（頻道名稱）**：打「**印藥水小幫手**」
　・**Channel description（說明）**：打「**透析品管 提醒小幫手**」
　・**Category / 大分類**：選「**醫療/醫院**」或「個人」都可以
　・**Subcategory / 小分類**：隨便選一個最接近的
　・**Email**：填你的 email
　・最下面**打勾同意**條款 → 按「**Create / 建立**」
　（中途若跳出要你「建立 LINE 官方帳號 / Official Account」，就跟著它建，名字一樣用「印藥水小幫手」即可）

**第 4 步**　🔑 拿金鑰（最重要！）
　建好後會進到那個頻道。上面有一排分頁，點「**Messaging API**」。
　往下滑找到「**Channel access token（long-lived 長期）**」
　→ 按「**Issue / 發行**」→ 會出現**一長串英數字**
　→ **整串複製，私訊傳給小巫**（這串就是金鑰 🔑，不要貼到群組！）

✅ 做到這裡先停！把那串金鑰傳給我就好，其他我來。

━━━━━━━━━━━━━━━
**PART 2：把機器人加進群（拿到金鑰後再做）**
━━━━━━━━━━━━━━━

**第 5 步**　把機器人加成好友
　在剛剛「Messaging API」那頁，往下找一個「**QR code（方形條碼）**」
　→ 用手機 LINE 的「**加好友 → 掃描**」掃它 → 把「印藥水小幫手」**加為好友**。

**第 6 步**　把機器人邀進品管群
　到你們要發名單的那個 **LINE 品管群** → 邀請成員 → 把「**印藥水小幫手**」拉進群。

**第 7 步**　傳一句話通知我
　做完傳「**好了**」給小巫，剩下最後一個小設定我用程式處理，不用你弄 🙆
