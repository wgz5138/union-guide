# 雲端 LINE 提醒 — 一次性設定（給小巫）

> 設定完成後就「全自動」：每天雲端自己跑，提醒明天要印藥水的人。
> 玉繡只需每週把名單貼進 Google 試算表；小巫只設定這一次。

---

## A. 建 Google 試算表（玉繡每週貼名單的地方）

1. 到 Google 雲端硬碟 → 新建一個「**Google 試算表**」，命名例如「印藥水本週名單」。
2. 第一列打三個欄位標題（順序要一樣）：

   | 印日期 | 區 | 姓名 |
   |---|---|---|

3. 下面就是每筆資料，例如：

   | 印日期 | 區 | 姓名 |
   |---|---|---|
   | 2026-06-21 | 一區 | 巫佳容 |
   | 2026-06-21 | 二區 | 邱玉繡 |
   | 2026-06-23 | 一區 | 劉于甄 |

   - 印日期 = 那個人「實際印藥水的那天」（程式輸出的「X 印」那天）。
   - 一筆一列；同一人印兩區就兩列。

4. **發布成 CSV**（讓雲端讀得到）：
   - 上方選單 **檔案 → 共用 → 發布到網路**
   - 左邊選「**整份文件**」或那一個工作表；右邊格式選「**逗號分隔值 (.csv)**」
   - 按「**發布**」→ 複製產生的網址（結尾是 `...output=csv`）
   - 這串網址就是下面要用的 **SHEET_CSV_URL**

---

## B. 把「金鑰」與「名單網址」放進 GitHub Secrets

1. 先**重發一把新金鑰**（安全）：
   LINE Developers → 頻道 2010388941 → Messaging API → Channel access token → **Reissue** → 複製新的。
2. GitHub 進到本 repo → **Settings → Secrets and variables → Actions → New repository secret**，新增兩個：
   - 名稱 `LINE_CHANNEL_TOKEN`　值＝剛剛 Reissue 的新金鑰
   - 名稱 `SHEET_CSV_URL`　值＝A 步驟的 CSV 發布網址

---

## C. 讓排程生效

- GitHub 的排程**只會跑「預設分支(main)」上的 workflow**。
- 所以要把這個分支的內容**合併到 main**（或把 `.github/workflows/line-reminder.yml` 放到 main）。
- 想立刻測試：到 GitHub 的 **Actions** 分頁 → 選「印藥水 LINE 提醒」→ **Run workflow**（手動跑一次）。

---

## D. 平常運作（全自動）

- 每天台灣時間 **10:00**，雲端自動執行 → 找出「明天要印」的人 → 私訊提醒本人。
- 想改時間：改 `line-reminder.yml` 裡的 `cron`（注意那是 UTC，台灣要 -8 小時）。
- 想「當天再補一次」：可再加一個排程用 `--target same`。
