# 表單用「個資蒐集告知＋同意」文字（可直接複製貼上）

> 用法：貼到 Google 表單「正式發起人資料表」的**說明欄**（表單最上方），並在最後加一題「**必勾同意**」的勾選題。
> 興趣連署表單（只收姓名/手機）可用「簡短版」。

---

## 【完整版】貼在「發起人資料表」最上方說明欄

```
【個人資料蒐集告知】
一、蒐集者：高榮企業工會（籌備中）。
二、目的：辦理工會連署發起、籌備聯繫，及向高雄市政府勞工局送件登記。
三、蒐集項目：姓名、身分證字號、出生年月日、通信地址、電話、部門/身分別等送件必要資料。
四、利用方式與期間：僅供上述目的使用；數位暫存檔於完成登記送件後刪除，不作其他用途、不提供無關第三人。
五、你的權利：你可隨時要求查詢、閱覽、更正、停止使用或刪除你的個資，洽工會籌備窗口辦理。
六、未提供之影響：屬送件法定必要欄位，若不提供將無法完成發起人登記。
※ 工會將以收緊權限、限定經手人、用後刪除等方式保護你的資料。
```

---

## 【同意題】在表單最後新增一題（單選・必填）

**題目：** 個人資料同意（必勾）
**選項（單選）：**
```
我已閱讀上方個資蒐集告知，並同意工會於上述目的內蒐集與使用我的個人資料。
```
> 設定為「**必填**」。未勾選不得送出。（現行表單已有類似一題，照此文字統一即可。）

---

## 【簡短版】興趣連署表單（只收姓名/部門/手機/Line）用

```
【個資告知】本表僅蒐集姓名、部門、手機、Line ID，供工會籌備聯繫之用，不作其他用途。
你可隨時要求刪除。勾選即表示同意。
```

---

## 設定小抄（Google 表單）
1. 開啟表單 → 最上方「表單說明」貼【完整版】。
2. 最後一題 →「＋」新增「**單選**」題 → 貼【同意題】→ 右下角開「**必填**」。
3.（建議）表單「設定 → 回應 → 收集電子郵件地址」可關閉非必要項目，落實資料最小化。
4.（建議）回應試算表的共用權限改為「**僅限指定人**」，不要用「知道連結的人」。
