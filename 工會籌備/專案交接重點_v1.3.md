## 1. 最重要的法律前提（不可搞錯，會影響「誰能入會」）

> 這段是地基。執行任何文件或對外文案前，都要符合這裡。

- 工會分三種：本案要的是**企業工會**（同一事業單位的勞工組成）。
- **誰能當會員/發起人**：高雄榮總是退輔會公立醫院，院內身分不同：
  - **正式公務人員（公職）不能加入企業工會**，他們走《公務人員協會法》的「公務人員協會」。
  - **約用、契約、派遣等「勞工身分」者才能發起、加入企業工會。**（我本人是勞工身分，OK。）
  - 工會法第14條：代表雇主行使管理權的主管，不得加入該工會。
- **成立門檻（工會法第11條）**：
  1. 需 **30 位以上勞工**連署發起 → 組「籌備會」→ 公開徵求會員、擬章程、開成立大會。
  2. 成立大會後 **30 日內**，備齊章程、會員名冊、理事監事名冊，向 **高雄市政府勞工局** 請領登記證書。
  3. 「公開徵求會員」要**留證據**（公告、信件、說明會紀錄）。
- **保護傘（工會法第35條）**：雇主若因組工會而拒僱、解僱、降調、減薪或妨礙，屬「不當勞動行為」，可向勞動部申請裁決，違法處分無效。組織期間記得保留紀錄。
- **省錢/省時關鍵**：高雄市政府勞工局有**免費諮詢與輔導**；勞動部對新成立工會有**教育訓練補助**。流程細節以勞工局範本為準。

## 3. 可交給 Claude Code 直接做的清單（核心）

> 標籤：✅現在就能完整做｜🕓需工會法人成立後收尾｜⚠️需人工/勞工局審核

### 3-1. 工會網站 + FAQ 規則機器人　✅
- 內容：工會介紹、章程、入會說明、常見問答、聯絡方式。
- 先做**規則式 FAQ 機器人**（預先寫好問答，免費、不會亂講），不要一開始上 AI。
- 技術建議：純前端網站（HTML/CSS/JS），**不需要 Anaconda**。要手機能看（RWD）。
- 不要做原生 App（工程大、要維護），用 RWD 網站 + Line 取代。

### 3-2. AI 自動回覆原型（雲端 API）　✅
- 用雲端 LLM API（Claude / OpenAI / Gemini），按用量付費，小工會月約幾百～一兩千元。
- **不要自建 AI 主機**（高階顯卡整機約 5–7 萬＋電費維護，現階段是錢坑）。
- 這部分若用 Python，可放在 Anaconda 環境；或讓 Claude Code 自建 venv 皆可。

### 3-3. 法規查詢助手 RAG 原型　✅
- **不要「把全部法規錄進去」**，量大又會過時。
- 做法：
  - 簡單版：網站放連結到全國法規資料庫（law.moj.gov.tw）對應法條。
  - 進階版（RAG）：全國法規資料庫有**開放資料 XML/JSON 可下載**（也有現成開源專案把它切成小檔），只下載**用得到的那幾部法**餵給 RAG。
- 用得到的法：工會法、勞動基準法、性別平等工作法、商標法、（成員若涉公職再看公務人員相關法）。
- 這部分是 Python，建議用 Anaconda 環境。

### 3-4. Logo 設計 + 轉向量圖　✅
- 為什麼要向量：旗幟、布條、刺繡、招牌、商標註冊都需要**向量檔（SVG/AI/EPS）**，AI 生圖是點陣（PNG/JPG）放大會糊。
- 工具：免費可用 Inkscape 或 vectorizer.ai；精緻可請設計師用 Illustrator 描。
- 可請 Claude Code 直接產出 SVG 版 Logo 草稿。

### 3-5. 成立文件草稿　⚠️（可起草，但需審核）
- Claude Code 可**起草**：章程、連署書、會員名冊表格、成立大會議程、籌備會會議紀錄範本。
- **務必**對照高雄市政府勞工局官方範本，並經勞工局/人工確認後才定稿。AI 草稿只是加速。

### 3-6. Line 官方帳號　🕓（部分要等法人）
- 基本灰盾帳號：現在可免費開來測（一對一聊天、自動回應不計費）。
- 收費：輕用量免費（每月約 200 則群發）／中用量月 800 元 3000 則／高用量月 1200 元 6000 則。
- 認證帳號（藍盾）：通常要有立案主體 → 等工會成立後辦。
- 串接（Python 接 Line Messaging API）可先寫好原型，等帳號就緒再上。

### 3-7. 不能靠 Claude Code 完成的（人工/外部）
- 法律登記、領登記證書、藍盾認證、商標註冊、法人銀行開戶、統一編號、稅務。
- 30 人連署、成立大會等實體程序。

## 8. 容易遺漏、但很重要的事項（補充）

> 標籤：✅現在可做｜🕓等法人後｜⚠️守法律底線｜💰錢的事｜🗓️時程

### 8-1. 個資與隱私（網站/Line 一收資料就適用）　⚠️
- 收會員姓名、員編、電話、會費紀錄 → 受《個人資料保護法》規範。
- 要做：**隱私權政策＋蒐集告知＋同意勾選＋資料安全保護**。Claude Code 可幫你起草隱私權政策。
- 群發 Line／Email 也要**事先取得同意**，不可亂發。

### 8-2. 數位資產「權限治理」（防單點失聯）　🕓
> 工會最常出事的地方：所有帳號都掛在某一個人名下，那人離職或鬧翻 → 工會整組失聯。
- 帳號盡量用「**工會公用 Email**」開，不要綁個人帳號。
- 至少**兩人**保管密碼；用密碼管理工具；登記好復原資訊。
- 列一張「**數位資產清單**」（帳號、誰保管、續費日）。Claude Code 可幫你做這張表。

### 8-3. AI／FAQ 機器人的「法律免責聲明」　⚠️
> 機器人回答勞動法問題可能答錯，會踩紅線。
- 明顯處標註：「本回覆僅供參考，非正式法律意見，正式問題以勞工局／律師為準。」
- AI 回答範圍限定在你餵的法條內（規格書 3-3 已寫）。

### 8-4. 名稱與 Logo 的權利風險　⚠️（商標法）
- 工會名稱用「高榮」一般可以（企業工會常以工作場所命名），但 **Logo 不要照抄醫院官方院徽**，以免侵權。
- 想保護自己的 Logo → 等工會成立後，**以工會名義註冊商標**。

### 8-5. 網域／主機的續費與備份　🕓
- 網域、主機要記**續費日**（過期沒繳 → 網站直接消失，是常見災難）。
- 網站原始碼、會員資料定期備份（你已有 Google 雲端備份習慣，延續即可）。

### 8-6. 啟動資金與簡易財務　💰
- 收到會費前的初期開銷（網域、印刷等）**誰先墊？先講好**。
- 做一張簡單「**會費／收支記錄表**」（你會 Excel，可用 xlsx）；財務公開有助信任與永續。

### 8-7. 時間軸：把 A 線法律進度和 B 線上線「綁在一起」　🗓️
- A 線到「成立大會」前 → B 線把**不需法人**的東西做完（網站、Logo、文件草稿、原型）。
- A 線「拿到登記證書」後 → 才收尾**藍盾、商標、法人銀行帳戶、金流**。
- 籌備會建議**各指定一人**：法律窗口、技術窗口、財務窗口（避免單點失聯）。
