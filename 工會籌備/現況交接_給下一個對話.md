### union_push.py 目前版本（只發鉤子、無網址）＝要貼上的內容
```python
# -*- coding: utf-8 -*-
import os, json, datetime, urllib.request, urllib.error
TOKEN = os.environ.get("LINE_TOKEN", "").strip()
RAW = os.environ.get("LINE_GROUP_ID", "").replace("，", ",")
GROUPS = [g.strip() for g in RAW.split(",") if g.strip()]
TZ = datetime.timezone(datetime.timedelta(hours=8))
START = datetime.datetime(2026, 6, 14, 20, 0, 0, tzinfo=TZ)
DEADLINE = datetime.datetime(2026, 6, 17, 23, 59, 59, tzinfo=TZ)
INTERVAL_HR = 4
QUOTES = [
    "別再等了，倒數結束就沒有下次——現在連署。",
    "你不簽，缺的就是你那一個。",
    "30 秒的事，別讓它變成「當初要是…」的遺憾。",
    "看到這則，就是在叫你現在點下去連署。",
    "猶豫的時間，夠你連署三次了。",
    "時間在跑、名額在跑，你還在滑——停下，簽。",
    "「等一下再說」＝這次大概就沒你了。",
    "倒數 ⏳ 6/17 23:59，門一關就不再開。",
    "不用你帶頭、不用你出面，你只要「簽下去」。",
    "一分鐘，換一個能替你談加班費的工會，划算。",
    "別讓「想組工會」永遠停在「想」——現在連署。",
    "手機就在手上，1 分鐘，現在點。",
    "現在不站出來，將來就少一個替你說話的位子。",
    "缺你這一筆，30 就湊不滿——靠你了。",
    "看完這句，手指往連署按下去，就現在。",
    "你這一票，就是「成立」跟「再等好幾年」的差別。",
    "別當那個事後才說「早知道就簽了」的人。",
    "門快關了，趁現在還來得及——簽下去。",
]
def push_to(gid, text):
    body = json.dumps({"to": gid, "messages": [{"type": "text", "text": text}]}).encode("utf-8")
    req = urllib.request.Request("https://api.line.me/v2/bot/message/push", data=body,
        headers={"Content-Type": "application/json", "Authorization": f"Bearer {TOKEN}"})
    try:
        resp = urllib.request.urlopen(req); print(f"OK -> {gid[:10]} HTTP {resp.status}")
    except urllib.error.HTTPError as e:
        print(f"ERR {gid[:10]} {e.code}: {e.read().decode('utf-8','ignore')}")
def main():
    if not TOKEN or not GROUPS:
        print("no token/group, skip"); return
    now = datetime.datetime.now(TZ)
    if now > DEADLINE:
        print("ended, skip"); return
    slot = int((now - START).total_seconds() // (INTERVAL_HR * 3600))
    if slot < 0: slot = 0
    text = QUOTES[slot % len(QUOTES)]
    print(f"slot {slot}, groups {len(GROUPS)}, text {text}")
    for g in GROUPS:
        push_to(g, text)
if __name__ == "__main__":
    main()
```
