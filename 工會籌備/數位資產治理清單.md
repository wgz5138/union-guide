# 高榮企業工會 數位資產治理清單

> 目的：防「單點失聯」——所有帳號都掛在一個人名下，那人離職/鬧翻/失聯，工會整組斷線。
> ⚠️ **本檔只記「有什麼、誰保管、何時續費」，絕對不要在這裡寫密碼、access token、驗證碼。** 密碼放密碼管理工具。
> 維護：每變動一次就更新；每季對一次。

---

## 一、治理三原則
1. **公用帳號優先**：能用工會公用 Email（kvgheu512）開的服務，就不要綁個人帳號。
2. **至少兩人保管**：每個關鍵帳號的密碼/復原資訊，至少兩位幹部知道（用密碼管理工具共享，不要用 LINE 傳）。
3. **記復原資訊＋續費日**：手機/備援信箱/復原碼要登記；會過期的（網域、主機）記續費日，過期＝服務消失。

## 三、密碼與機密的保管方式
- **密碼管理工具**（建議 Bitwarden 免費版，可建「工會組織保險庫」共享給指定幹部）。
- LINE 的 `LINE_TOKEN`、`LINE_GROUP_ID` 等機密：放 GitHub repo 的 **Secrets**（已是現況），**不要寫進任何文件或訊息**。
- 紙本復原碼：影印一份密封，交財務/法律窗口分開保管。

## 四、交接與離開時（offboarding）
當有幹部離開或交接：
- [ ] 變更其知道的關鍵密碼。
- [ ] 移除其對雲端資料夾/表單/repo 的存取權。
- [ ] 確認備援保管人補位，更新本清單。
- [ ] 若其為某服務唯一保管人 → 先轉移再移除。
