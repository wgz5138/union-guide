# 工會籌備 · 工作分配後台（Google Apps Script Web App）

一頁式漂亮網頁 + 可改狀態的後台，直接掛在工作分配試算表上。
誰按「完成」，所有幹部即時看到同一份進度，附大進度條。

## 安裝（一次就好）
1. 打開工作分配試算表 → 上方 **擴充功能 → Apps Script**
2. 把 `Code.gs` 內容貼進預設的 `Code.gs`
3. 左側 **＋ → HTML**，檔名取 **`Index`**，把 `Index.html` 內容貼進去
4. 上方 **部署 → 新增部署作業 → 類型「網頁應用程式」**
   - 執行身分：**我**
   - 誰可以存取：**所有人**（幹部點連結免登入直接用）
5. **部署** → 第一次授權 → 複製「**網頁應用程式網址**」
6. 把網址貼到幹部 LINE 群；手機可「加到主畫面」當 App 用

> 之後若改了程式碼：**部署 → 管理部署作業 → 編輯(鉛筆) → 版本選「新版本」→ 部署**，才會生效。

## 試算表欄位
程式用「標題列關鍵字」自動對欄位，順序變動也不會壞：
`區塊 / 工作項目 / 負責人 / 時間 / 狀態 / 備註`。
狀態值固定為 `待辦 / 進行中 / 完成`。
