## 4. 關鍵發現／決策（避免重踩、避免亂講）
- **Travelpayouts 免費資料 API** = 別人最近 48h 搜尋過的**快取** → 冷門航線/遠期日期常「查無票價」（非 bug）。
- Travelpayouts **即時搜尋 API** 門檻：App **MAU ≥ 5 萬**，個人拿不到。
- **LINE Notify 已於 2025/3/31 停用** → 改用 Telegram。
- **Amadeus 免費自助版 2026/7/17 關閉**（amadeus_flights.py 僅留參考）。
- 想「盯特定航線、真實即時、免費」最實際 → **Google Flights 內建「追蹤價格」**（網站設定，非程式）。
- **Google Flights 爬取要點**：
  - `q=Flights from KHH to NRT on 2026-09-15 oneway` 的網址可**預填搜尋**。
  - 會**間歇出現「系統發生錯誤」** → 必須**重試**（正式版 MAX_TRIES=8）。
  - **headless=True 易被擋** → 用 `headless=False`。
  - **stealth（隱藏 webdriver 等）＋ 持久設定檔** 大幅提高成功率（實測有效）。
  - 結果卡無固定 class → 用「內容含 $價格＋小時＋時間」找 `li`，再用正則解析。
  - 時間是中文制（清晨/上午/中午/下午/晚上/凌晨 + h:mm）；轉機寫「直達」或「轉機 N 次」。
  - **詳情頁（點一班後）有「行李」**：例「免費攜帶 1 件手提行李／第 1 件託運行李須加收費用」。
  - **詳情頁沒有「航班號」** → 誠實結論：Google Flights 不提供航班號（需航空官網/GDS）。
