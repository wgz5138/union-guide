## 一、一句話

我已實作一套**自動化機票數據抓取系統並實際運行**：針對本案的 Google Flights 目標，已用 Playwright 實際抓到指定航線/日期的機票資料（票價、轉機次數、起降時間、航空公司），並以 stealth＋持久化設定檔＋自動重試解決反爬與間歇錯誤、結構化輸出 CSV/JSON。另有一套雲端每日自動執行的 API 版監測系統佐證完整工程能力。以下逐條對照貴案需求，並誠實標示完成度（長期穩定運行仍需維護，航班號/行李為可擴充項目）。

## 三、技術棧

- **Python**（`requests` / `Playwright`）
- **Playwright（Chromium）**：處理 JavaScript 動態渲染、模擬真實瀏覽器
- **排程**：GitHub Actions（雲端，免顧機）／Windows 工作排程器（本機）
- **儲存**：CSV、JSON（可依需求改資料庫，如 SQLite/MySQL）
- **通知**：Telegram Bot（可改 Email 等）
- **穩定性設計**：重試＋退避、逾時、日誌輪替、設定與密鑰分離（環境變數）

---

## 四、系統架構

```
   排程（雲端 GitHub Actions／本機工作排程器）
                  │ 定時觸發
                  ▼
   Playwright 開瀏覽器 → 載入 Google Flights（指定航線/日期）
                  │ 等待動態渲染、處理同意視窗
                  ▼
   解析：票價／轉機／時間／航空（→ 詳情頁補航班號、行李）
                  │ 重試・逾時・日誌
                  ▼
   結構化儲存（CSV + JSON）  ──→  降價偵測 ──→ 通知（Telegram/Email）
```
